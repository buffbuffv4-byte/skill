# SkillOpti (CS2) 0.2.0 BETA

Небольшое Windows-приложение на C++20 и Qt 6 Widgets.

## Реализовано
- Мониторинг загрузки CPU, использования RAM и места на системном диске.
- Сканирование характеристик компьютера.
- Поиск временных файлов в папке временных файлов текущего пользователя с предварительным просмотром и подтверждением удаления.
- Game Boost: запуск Counter-Strike 2 через Steam, открытие настроек игрового режима Windows и копирование необязательного параметра `-novid`.

## Пока не реализовано
- Автоматические оптимизации FPS.
- Профили конфигурации CS2/Rust/Minecraft.
- Управление автозагрузкой и журнал отката системных настроек.
- Исторические графики и мониторинг температур.

Game Boost не обещает прирост FPS и не меняет системные настройки автоматически. Не отключает антивирус, защиту Windows или системные службы.

## Сборка через GitHub Actions
В репозитории должен оставаться существующий файл `.github/workflows/build-windows.yml`. После каждого commit открой вкладку **Actions / Действия**, дождись зелёной галочки и скачай артефакт `SkillOpti-Windows`.

## Локальная сборка
Нужны Visual Studio 2022 с C++ Desktop workload и Qt 6 для MSVC 2022 x64. Затем настрой `CMAKE_PREFIX_PATH` на каталог Qt и собери проект через CMake.
