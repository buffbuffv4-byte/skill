# SkillOpti 0.1.0 BETA

Первая исходная версия для Windows 10/11, C++20, Qt 6 Widgets, CMake и MSVC.

## Что уже работает

- Мониторинг CPU (Windows `GetSystemTimes`), RAM (`GlobalMemoryStatusEx`), системного тома, ОС и времени работы. Обновление примерно раз в секунду.
- Сканирование процессора, адаптера дисплея, RAM, накопителей, архитектуры и количества логических потоков.
- Безопасное сканирование временной папки текущего пользователя.
- Выбор файлов, предварительный просмотр, подтверждение удаления, подсчёт удалённых/пропущенных файлов и освобождённого места.
- Тёмный интерфейс SkillOpti.

## Что пока не реализовано

Game Boost, игровые профили, управление автозагрузкой, графики истории, датчики температуры и откат системных изменений. Эти страницы честно обозначены как находящиеся в разработке и ничего не меняют. Температурные датчики нельзя достоверно получить универсальным Windows API без дополнительной поддержки оборудования/библиотеки.

## Требования

- Windows 10 или Windows 11 x64
- Visual Studio 2022 с workload **Desktop development with C++**
- CMake 3.21+
- Qt 6.x, комплект **MSVC 2022 64-bit**, компонент Qt Widgets
- Git необязателен

## Сборка

1. Установите Visual Studio 2022 и выберите **Desktop development with C++**.
2. Установите Qt 6 через Qt Online Installer. Выберите комплект `MSVC 2022 64-bit` и Qt Widgets.
3. Установите CMake.
4. Откройте **x64 Native Tools Command Prompt for VS 2022** или обычный терминал с MSVC в PATH.
5. Перейдите в папку проекта и задайте путь к Qt, например:

   ```bat
   set QT_DIR=C:\Qt\6.8.3\msvc2022_64
   ```

   Укажите фактическую папку установленной версии Qt.
6. Запустите `build.bat`.
7. После успешной сборки файл будет находиться в `build\Release\SkillOpti.exe`.

## Автоматическая сборка (GitHub Actions)

Файл `.github/workflows/build-windows.yml` собирает проект на `windows-2022` (Qt 6.8.3, MSVC 2022 x64, CMake + Ninja, Release), разворачивает Qt DLL через `windeployqt` и публикует артефакт `SkillOpti-win64` (ZIP с `SkillOpti.exe` и DLL). Запуск: вкладка **Actions → Build Windows x64 → Run workflow** или любой push. Результат: страница запуска → раздел **Artifacts**.

## Запуск на другом компьютере

Qt-приложение обычно требует Qt DLL рядом с EXE. В терминале, где доступен комплект Qt, выполните:

```bat
"C:\Qt\6.8.3\msvc2022_64\bin\windeployqt.exe" "build\Release\SkillOpti.exe"
```

Замените путь на фактический. После этого можно переносить папку с EXE и добавленными DLL, а не один EXE.

## Безопасность очистки

Очистка ограничена каталогом временных файлов текущего пользователя, пропускает символьные ссылки и повторно проверяет путь непосредственно перед удалением. Файлы удаляются напрямую, не через корзину, поэтому приложение показывает отдельное подтверждение. Не удаляйте файлы, если не понимаете, что они делают.

## Ограничения

- Первый отсчёт CPU может отображаться как «Сбор данных…», так как процент вычисляется между двумя измерениями.
- Название GPU получено из списка Windows display devices и может показывать виртуальный/удалённый адаптер.
- «Системный диск» на главной — том, соответствующий корню Windows-пути приложения.
- Для сборки нужен установленный Qt и MSVC. Эта среда не гарантирует выпуск и проверку готового Windows EXE, поэтому сборка выполняется на Windows по инструкции.
